# Module 4: Security Tools & Technologies — Notes & Glossary

## Key Concepts
* **SIEM Systems:** Learned how tools like Splunk and Google Chronicle aggregate logs across networks to spot anomalies.
* **Linux Environment:** Explored basic command-line operations for navigating systems and managing file permissions.
* **SQL Querying:** Used database queries to filter security logs and search for specific security events.
* **Python Scripting:** Examined how security analysts use scripts to automate routine tasks and log parsing.

---

## Terms & Definitions
* **SIEM (Security Information and Event Management):** A tool that collects, analyzes, and correlates log data from across an enterprise.
* **CLI (Command Line Interface):** A text-based program used to run operating system commands.
* **SQL (Structured Query Language):** A programming language used to manage and query relational databases.
* **Log:** A record of events created by applications, devices, or operating systems.
